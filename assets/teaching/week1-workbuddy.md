## 0. 先看这里：这份文件怎么用（30 秒）

这份文件有 **两种用法**，你选一种就行：

| 用法 | 怎么做 | 适合谁 |
| --- | --- | --- |
| **用法 A：人读版** | 你现在就在读，照着往下走，每一步都有截图位置说明和检查点 | 第一次装，喜欢一步步确认的同学 |
| **用法 B：AI 带教版** | 先按用法 A 把 WorkBuddy 装好、登录好；然后**把这份文件直接拖进 WorkBuddy 对话框**，发一句：「按这份文件带我走完初始化，我做到哪一步就问我，别一次性讲完」 | 想让 AI 手把手教、边做边问的同学 |

> ⚠️ **重要提示**：WorkBuddy 没法自己把自己装进电脑（鸡生蛋问题）。所以用法 B 的前提是——你**先把软件装好、登录进去**，之后再让它读这份文件带你做"初始化"和"验收"。

## 1. 为什么值得花这 25 分钟

先说你平时是不是这样：

- 想找上周老师发的 PDF，在微信群、钉钉群、相册、下载文件夹里翻了 10 分钟
- 小组作业要交一份 PPT，从建文件到排版熬到凌晨两点
- 写课程论文，参考文献格式改了 8 遍还是不对
- 实习投简历，每个岗位都要重新改一遍简历措辞

这些事的共同点是：**有固定套路、反复要做、费时间但不需要创造力**。

WorkBuddy 干的就是这件事——它不是"又一个聊天机器人"，而是**能真的操作你电脑文件的 AI 同事**。你说一句话，它自己拆任务、自己干、最后交给你一个能直接用的文件。

**一句话区分它和普通 AI：**

| | 普通 AI 对话 | WorkBuddy |
| --- | --- | --- |
| 能力 | 只能对话、给建议 | 能实际执行任务 |
| 文件 | 需要你手动操作 | 自动操作本地文件 |
| 任务 | 单步骤、简单任务 | 多步骤、复杂任务 |
| 结果 | 输出文字回复 | 交付可验收的结果 |

**本周装完，你至少能拿到 3 个立刻能用的结果**（后面第 5 步会让你现场跑一个）。

## 第 4 步：完成初始化（这一步决定它好不好用）

刚装好的 WorkBuddy 是"失忆"的——不认识你、不知道你在学什么、手上没有工具。这一步我们把它变成**你的**助手。

一共 5 小步，**每一小步都是对着它说一句话**，不用点任何设置菜单。

### 4.1 认识「工作空间」：先给它一个工位

**工作空间 = 你允许 WorkBuddy 读写的那个文件夹。** 它只能在这个文件夹里活动，不会乱翻你整个电脑。

这一步看着简单，但**跳过它的人最多，吃亏也最直接**。两种典型惨状：

| ❌ 烂做法 | 后果 |
| --- | --- |
| 不管它，直接开始任务 | 文件生成在默认目录里，**下次你根本找不到它在哪** |
| 把整个 D 盘或桌面设成工作空间 | 它可能翻到你的私密资料；无关文件太多，它也容易被带偏 |

一句话理解：**工作空间就是它的工位。你得先给它一张桌子，它才知道东西往哪放、从哪拿。**

#### 第一步：你自己动手建这个文件夹（手动，1 分钟）

> 这一步**故意不交给 AI**——你要亲自知道自己文件放在哪。

**Windows**

1. 按 `Win + E` 打开「文件资源管理器」
2. 双击进 D 盘（没有 D 盘就选一个空间够的盘，**别用 C 盘**）
3. 在空白处**右键 → 新建 → 文件夹**，命名 `AI工作区`
4. 双击进去，再建三个子文件夹：`01-原始资料`、`02-我的项目`、`03-产出`

**macOS**

1. 打开「访达（Finder）」，左侧点「文稿」
2. 在空白处**右键 → 新建文件夹**，命名 `AI工作区`
3. 双击进去，再建三个子文件夹：`01-原始资料`、`02-我的项目`、`03-产出`

建完长这样：

```
AI工作区/
├── 01-原始资料/     ← 课件、PDF、截图，往里丢
├── 02-我的项目/     ← 每个项目一个子文件夹
└── 03-产出/         ← 它给你生成的成品放这儿
```

#### 第二步：在 WorkBuddy 里选中它

回到 WorkBuddy，在对话输入框**左下角**点 **「选择工作空间」**，选中刚建的那个 `AI工作区`。

（不是点设置菜单，就是这个输入框左下角的按钮。找不到就用眼睛扫一遍输入框四周。）

#### 第三步：一句话把规矩立下来

选中之后，把这段发过去：

```
这是我的工作空间。以后所有生成的文件都放在这里，
按「项目名」建子文件夹，别把东西散着放。
动手改或者删我的文件之前，先告诉我你打算改什么。
```

#### 第四步：验证一下真的选上了（别跳过）

```
你现在的工作空间是哪个目录？把这个目录下的文件列一下给我看。
```

它报出来的路径应该**正好是你刚建的那个文件夹**。

> ⚠️ **对不上就是没选上**——重选一次。这一步不做，你后面所有"文件去哪了"的困惑都从这儿来。

> 🎯 **为什么现在就要养成「一个项目 = 一个文件夹」的习惯？**
> 第 3 周做 Skill、第 4 周做个人网页，**全都是在一个文件夹里干活**。
> 尤其是第 4 周，标准结构就是 `index.html` + `style.css` + `script.js` + `assets/`
> 四个东西放在**同一个文件夹**里——放散了，网页直接打不开。
> 你现在把这件事练成肌肉记忆，后面两周能省掉一大堆麻烦。

### 4.2 让它认识你

这一步是"绑定身份"。**直接把下面这段复制过去改一改**：

```
帮我记住这些关于我的信息，以后默认按这个来：

- 我是香港中文大学（深圳）的学生，专业是____，现在读____年级
- 我最近在忙的事：____（比如：期末复习 / 考研 / 找实习 / 社团招新）
- 我常用的工具：微信、WPS、腾讯文档
- 跟我讲话用大白话，别端着，别写"感谢您的提问"这种话
- 每次给我结果之前，先告诉我你打算怎么做，我确认后再动手
- 不确定的信息别编，直接说"这个我不确定"
```

### 4.3 挑一个你喜欢的语气（人格）

同一个 AI，换个语气，用起来感觉完全不一样。

```
从现在开始，你扮演一个带我做项目的学长/学姐。
说话直接、有耐心、不说套话。我搞错了就直说，别客气。
每次帮我的时候，顺手告诉我"这一步为什么这么做"。
```

### 4.4 装上第一批技能

技能 = 给 AI 的一本"专项作业手册"。装上之后，它在对应场景下的表现会专业很多。

**直接说这句**：

```
你现在的技能列表里有哪些？按"跟学生场景相关"帮我挑 3 个最值得先装的，
装上之后分别能帮我做什么，各给我一个例子。
```

它会列出可装的技能并帮你装。

### 4.5 连上你的数据线

"数据线"就是让 WorkBuddy 能碰到你的外部工具（日历、邮箱、腾讯文档、腾讯问卷等）。

```
我现在最需要连上的外部工具是（按优先级）：
1. 腾讯文档
2. 腾讯问卷或腾讯会议

告诉我怎么连、连上之后能帮我做什么。暂时不想连的先跳过。
```

> 💡 连外部工具需要你在弹出的授权页面点"同意"。这属于安全操作，看清楚授权范围再点。

**✅ 检查点 4**：两件事——① 你有一个自己建的 `AI工作区` 文件夹，能让 WorkBuddy 报出它的完整路径；② 你能对它说出你的专业、年级、正在忙的事，它记得住。

## 第 5 步：跑通你的第一个任务（现场就干）

现在验收——**挑一个，把下面整段复制进对话框**，一个字都不用改：

### 选项 A：把一堆乱文件整理好

```
我的工作空间里文件很乱。请你：
1. 先列一遍里面有什么，按类型分组给我看
2. 提出一个整理方案（哪些文件夹、怎么命名），等我确认
3. 确认后帮我建文件夹并把文件移进去

改之前先给我方案，不要直接动手。
```

### 选项 B：给你自己做一个学习计划

```
帮我做一个期末复习计划。
我会告诉你课程名和考试日期，你帮我：
1. 按剩余天数倒排，标出最危险的科目
2. 每天拆成"上午理解、下午做题、晚上复盘"三段，每段不超过2小时
3. 单独标出最容易拖延的那一天，给我一个"只要5分钟就能启动"的最小动作
输出成一份 Markdown 文件，存到我的工作空间里。
```

### 选项 C：让文件自己去找你

```
帮我做一个信息归集任务：
每天早 8:30，汇总过去 24 小时 AI 领域最重要的 3 条进展，
每条写清楚：发生了什么、跟我们大学生有什么关系、来源链接。
输出成 Markdown 存到工作空间。
先把规则整理成一份详细的 Prompt 给我看，我确认后你再设为每天定时执行。
```

> ⚠️ **关于"定时任务"必须知道的一件事**：WorkBuddy 是跑在**你电脑上**的本地应用，定时任务的调度器也在本地。**电脑关机 = 到点不会执行**。想让它每天准点跑，电脑得开着。这也是它和云端服务的最大区别。

**✅ 检查点 5**：右侧「结果区」出现了一个真实的文件，你能点开看。

## 5. 卡住了怎么办（高频问题）

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| Win 弹出蓝色警告窗口 | 系统对新软件的正常拦截 | 点「更多信息」→「仍要运行」 |
| Mac 提示"无法打开，来自身份不明的开发者" | macOS 安全策略 | 系统设置 → 隐私与安全性 → 点「仍要打开」 |
| **Mac 装完打不开 / 提示"已损坏" / 一开就闪退** | **下载了错误芯片的安装包** | 苹果菜单 → 关于本机 → 看「芯片」：Apple M 系列选 **Mac ARM64**，Intel Core 选 **Mac x64**，重新下载 |
| 官网上找不到下载入口 | 首页内容比较长 | 一直往下拉到**页面最底部**，那里是「立即下载」区域 |
| 二维码扫不出来 / 扫码后没反应 | 网络或弹窗被拦 | 换手机网络、刷新页面；实在不行把二维码保存到手机相册，用微信"从相册识别" |
| 装完找不到图标 | 装到了非默认路径 | Win 按 `Win` 键搜；Mac 用 `Cmd + 空格` 搜 `WorkBuddy` |
| 它不给文件，只给一段文字 | 没设置工作空间 / 没说清要什么格式 | 说清楚："输出成 Markdown / Word / Excel 文件，存到工作空间" |
| **生成的文件找不到** | 工作空间没选上，文件落到默认目录了 | 问它："你刚才那个文件存到哪个路径了？" 再回去把工作空间重选一次（见 4.1） |
| 它说的工作空间路径不对 | 选错了文件夹，或者中途换了任务目录 | 重新点输入框左下角「选择工作空间」，选对之后让它再报一次路径 |
| 它瞎编了一个信息 | 大模型幻觉 | 直接说："这条我不确定，帮我标出来并给出真实来源，找不到就说找不到" |
| 任务跑到一半停了 | 积分不足 / 需要你确认 | 看屏幕上的提示，该确认就确认；积分不够去官网看看有没有校园活动 |
| 电脑关了任务没跑 | 调度器在本地 | 保持电脑开机（睡眠可以设成不休眠），或用云服务器 |

**还是搞不定？** 在群里按这个格式发，别人好帮你：

## 6. 举一反三：装完之后还能拿它做什么

WorkBuddy 的价值不在"装上了"，在"你让它替你干什么"。给你 4 个**校园场景**，直接抄：

## 附录：给想深挖的同学

**它的活儿是怎么干完的？**（一句话版）

1. **触发层**：什么时候开工（你手动发起，或者到点自动唤醒）
2. **任务层**：要做什么（你的那句话会被整理成一份详细的"任务说明书"）
3. **能力层**：用什么工具干（联网搜索、读写文件、跑脚本、调外部工具）
4. **交付层**：产出什么（本地文件、网页、表格、消息）

大模型本身**不会上网、不会发消息、不会写文件**——它只负责"决定下一步做什么"，真正动手的是 WorkBuddy 替它调用的工具。

**为什么有人写一句话效果很好，你写一句话效果很烂？**

差别在四个要素有没有说清楚：

- **角色**：你是谁、以什么身份干这件事
- **任务**：具体做什么
- **输入**：拿什么数据、参考什么
- **输出**：要什么格式、多长、给谁看

把"帮我写个简历"换成"你是 HR，帮我把这段经历改写成 3 条有数据的项目经历，每条不超过 40 字，用于投互联网运营岗"——效果完全是两个东西。
